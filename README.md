# Забытая оранжерея: Шёпот стекла

Завершённая игровая сборка браузерного 3D-приключения на Three.js (без npm, сервера приложений и внешних игровых ассетов). Интерфейс на русском языке. 3 главы, водяная головоломка, зеркала, 3 вида выращиваемых растений, пыльца и порча, три эссенции, победа и поражение.

## Запуск

Распакуйте архив, перейдите в папку `forgotten-greenhouse` и выполните `python -m http.server 8000`, затем откройте `http://localhost:8000`. Интернет необходим для загрузки фиксированной версии Three.js с CDN. Не запускайте через `file://`.

## Управление

WASD — движение, мышь — обзор, E — взаимодействие, J — дневник, Esc — пауза. При отсутствии Pointer Lock удерживайте левую кнопку мыши для обзора. На сенсорных устройствах есть виртуальный джойстик, кнопки E, дневника и паузы; обзор — перетаскиванием по 3D-сцене.

## Прохождение

1. Прочитайте дневник на столе возле входа. В западной зоне поверните вентили в порядке II → I → III.
2. Найдите горшок Moonbell в северо-западной части сада. Посадите, поддерживайте влажность 60–85% и лунное освещение, соберите Moon Essence.
3. В северо-восточной части поверните три зеркала до положений 2, 4 и 1 (положения начинаются с 1). Посадите Emberbloom, поддерживайте влажность 25–50% и солнечный свет, соберите Ember Essence.
4. Возьмите пыльцу у кристалла в лунном саду. Очистите горшок Starveil в юго-восточной части. Поддерживайте влажность 45–65% и сбалансированный свет. Соберите Star Essence.
5. Подойдите к центральному кристаллу и активируйте Сердце.

Вода пополняется автоматически. Пыльца появляется повторно. Погибшие растения можно пересадить. Сад теряет энергию со временем; выращенные эссенции её восполняют. При нулевой энергии наступает поражение. Рекорд сохраняется в localStorage (с try/catch). Для ускоренного тестирования добавьте `?test` к URL — тестовый режим не сохраняет рекорд.

## Технологии

HTML5, CSS3, Vanilla JS ES Modules, Three.js r170, WebGL, requestAnimationFrame, Web Audio API, localStorage. Архитектура, мебель, растения, витражи и материалы процедурные. Музыка и эффекты синтезируются Web Audio API после нажатия «Начать».

## Известные ограничения

Текущая версия не проходила полноценного автоматического браузерного e2e-тестирования; поведение WebGL и производительность на разных GPU требуют ручной проверки. Свет от витражей стилизован, а не физически рассчитан. Зеркальная оптика дискретная. Мобильный обзор работает жестом по канвасу, а не в области джойстика. Ориентир длительности 10–20 минут не подтверждён плейтестами.

## Чек-лист

Проверьте: запуск; меню; WASD; мышь; столкновения; E; дневник; последовательность вентилей; рост, полив и сбор Moonbell; положения зеркал; Emberbloom; сбор пыльцы; очистку Starveil; победу; поражение при нулевой энергии; рестарт 5 раз; сохранение рекорда; звук; паузу при скрытии вкладки; сенсорные кнопки.

Разработано программно с помощью ChatGPT без Blender и сторонних игровых ассетов.

## Финальная структура сюжета
Глава I: только три сюжетных растения и эссенции, свободные семена заблокированы. Вентили II-I-III, зеркала 2-4-1, три эссенции, активация Сердца клавишей E возле алтаря.
Глава II: Сердце меняет цвет с холодного голубого на золотой, открываются семена и посадка в покупные горшки, продажа и бесконечное обустройство. Кошки стоят 150 моры. Дневник (J) содержит справочник по обеим главам.
